# Envoi d'Emails Automatique avec Sendinblue

Ce projet est une application Python utilisant Tkinter pour envoyer des emails en masse à partir d'une liste de destinataires contenue dans un fichier CSV ou JSON. Il utilise le service SMTP de Sendinblue pour l'envoi des emails.

## Fonctionnalités

- **Chargement des destinataires** : Charge les adresses email à partir de fichiers CSV ou JSON.
- **Interface graphique** : Simple interface utilisateur construite avec Tkinter.
- **Envoi en masse** : Envoie des emails à tous les destinataires avec une barre de progression pour suivre l'envoi.
- **Gestion des erreurs** : Affiche des messages d'erreur en cas de problèmes lors de l'envoi.

## Technologies Utilisées

- Python
- Tkinter
- smtplib
- CSV
- JSON
